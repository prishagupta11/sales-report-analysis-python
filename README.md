📊 Sales Analysis System

A Python-based application for managing product sales data and generating analytical reports using Pandas and Matplotlib.
The system allows users to store product details, view sales records, and analyze business performance through different visual reports.

🚀 Features

| Feature               | Description                                |
| --------------------- | -------------------------------------------|
| 🛒 Add Sales Data     | Enter and store product details            |
| 📁 CSV Storage        | Saves records automatically for future use |
| 📋 Sales Report       | View complete sales data                   |
| 📈 Category Analysis  | Analyze sales by product category          |
| 🏷️ Brand Analysis    | Compare sales between brands                |
| 💰 Profit/Loss Report | Calculate brand/category performance       |
| ⭐ Rating Analysis     | Display top-rated products                |
| 📷 Export Charts      | Save generated graphs as images            |

📊 Available Analysis

# Sales by Category
Visualizes total units sold across different categories:
* Clothing
* Footwear
* Accessories
* Beauty
* Home & Living

# Profit/Loss Analysis
The system calculates:
Profit/Loss = Selling Price - Cost Price
and compares results between brands and categories.

# Top Rated Products
Displays the highest-rated products from the sales dataset.

# Sales by Brand
Shows brand-wise sales performance using charts.
